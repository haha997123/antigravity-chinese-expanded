# Antigravity 中文界面补丁 · 扩展版

面向 **Windows 版 Google Antigravity 2.33.0** 的非官方界面汉化补丁。插件、技能及相关产品名称保留英文，介绍、按钮、分类、设置说明等界面文字译为中文。

本版在上游补丁基础上补充展开区域的漏译，包括“更多插件”、插件详情、内置技能介绍、高级权限设置、项目说明、反馈表单和模型使用情况及状态提示、配额倒计时和权限确认框。词典共 **4,427 条**，其中包含 **227 条插件详情示例请求**。这些数字表示当前收录的词条数量，不代表未来新增或服务端动态内容均已覆盖。

v1.0.10 延续 2.33.0 已验证的适配代码，补入项目及 SSH 搜索、终端全选、旁支提问、免费和 Plus 配额等 8 条过去在本机补上的译文。

v1.0.9 适配 Windows Antigravity 2.33.0。补译文件变更卡片的「查看变更」、会话中的工作时长和进度更新、Gemini 4 Neon 公告正文及模型选择器说明。补丁启动客户端时使用客户端安装目录，安装包解压目录可在安装后清理。

v1.0.8 补充 Electron 原生右键菜单及递归子菜单汉化（会话、项目、分组、消息、链接、标签页与内置浏览器菜单，保护用户自定义分组名与 WSL 发行版名），补齐 18 项菜单固定词条（词典共 **4,415 条**），优化 `.cmd` 脚本对本机 Node.js 路径的自动探测，并在工作流文档中补充 Antigravity 宿主环境维护规范。

v1.0.7 适配 Antigravity 2.32.2，并将标准任务完成通知改为固定中文提示。增加可选的未来会话自动中文标题：仅处理启用后的新主会话，在后台自动标题生成后请求一次简短中文翻译，并合并保存标题。保留启用前会话；若你之后自行重命名，已完成的自动命名不会重复覆盖。此功能通过本机 chinese-title-settings.json 显式启用；新标题会额外使用一次模型请求，失败最多重试一次。主程序内运行，无需新增桌面插件。


v1.0.7 同时补充 MCP 配置与认证、服务器启动失败、自动化凭据到期、项目排序、应用搜索空状态及固定模型评选问卷。只翻译确定的界面文案；动态名称、诊断和输入答案保留原值。

v1.0.6 补充服务端数值小时配额（如 5-hour limit）的完整恢复倒计时，数字与时长跟随实际显示更新；每周配额原有翻译保留。同时补充 Chrome DevTools 与 Context7 的技能介绍，并修复项目删除说明中的 including。

v1.0.5 修正真实用户消息结构中的首条和后续消息时间，覆盖时间推进、消息重新渲染和新建会话；只翻译明确的时间控件。系统通知按来源翻译固定标题，保留问题、命令和 URL 原文。v1.0.7 将标准完成通知改为固定中文“智能体已完成任务，点击查看结果。”，避免英文摘要再次出现在系统提示中；点击仍定位到原会话，不修改会话正文。固定窗口标题在文本变化、标题替换和延迟创建时更新，用户生成的会话标题不作强行替换。下载更新后，仍需保存工作、退出客户端并重新应用补丁，运行中的软件才会在重启后使用新版。

v1.0.4 补充 Pro 配额说明的两种服务端句式、Gemini 新模型公告、Argon 独立配额与 Ultra 方案差异说明、Orchestrator 模型介绍和模型“新增”徽标。小时数、模型名称及版本随实际显示内容取值。

v1.0.3 补充加载、错误、空状态、账号许可、订阅限制、AI 积分和工具卡等隐藏界面分支，并增加 **250 条动态提示规则**。消息时间会在新建会话、首条消息出现及时间变化时自动更新为中文；模型名、资源名、数字和日期取自实际界面。

工具卡、问卷、表单校验和代码块工具栏只处理确认属于界面的文案。输入值、实际命令与输出、权限选择及作用域保持原有行为。

普通界面汉化不改写模型生成的内容。可选的自动中文标题功能在后台标题生成后处理本机新会话；模型服务不可用、额度不足或接口变化时可能仍保留原文，不能保证所有标题都能转换。服务端以后下发的新文案仍可能需要更新词典或句式。

## 适用范围

- Windows Antigravity **2.33.0** 使用 [v1.0.10](https://github.com/haha997123/antigravity-chinese-expanded/releases/tag/v1.0.10)，**2.32.2** 使用 [v1.0.8](https://github.com/haha997123/antigravity-chinese-expanded/releases/tag/v1.0.8)，**2.32.1** 使用 [v1.0.6](https://github.com/haha997123/antigravity-chinese-expanded/releases/tag/v1.0.6)。
- 插件和技能名称保留英文，界面说明使用中文。
- 补丁修改安装目录中的 `resources/app.asar`，首次应用时创建备份，可使用命令还原。
- 界面翻译仅注入 Antigravity 的本地应用页面；代码编辑区、输入内容、会话正文和技能原始定义不作为界面文案翻译。
- 软件更新可能覆盖补丁。更新后需要重新打补丁；如版本已变化，请先确认该版本的兼容性。

模型公告和配额重置说明按句式翻译，模型名、日期和数值实时取自客户端，不固定为截图中的日期。本补丁不会自动下载 GitHub 更新；新的句式需要维护词典或规则。

其他 Antigravity 版本及 macOS、Linux 未在本分支中验证。


发行包按 **Antigravity 客户端版本** 保留该版本的最后一个适配包，发行标题标明主要适配版本；不按补丁版本号一律删除历史包。

## 安装

1. 安装 Windows 版 Antigravity 和 Node.js 18 或更高版本。
2. 从 [Releases](https://github.com/haha997123/antigravity-chinese-expanded/releases) 下载与你客户端版本对应的安装 ZIP，解压后在目录中打开 PowerShell。
3. 保存正在进行的工作并退出 Antigravity，然后执行：

```powershell
npm ci --ignore-scripts
node .\patch.js
```

脚本会备份原始 `app.asar`、应用补丁并重新启动 Antigravity。默认会查找当前用户的 Antigravity 安装目录。

也可以双击 `install.cmd` 安装，双击 `restore.cmd` 还原。脚本会检查客户端版本、备份的 SHA-256 和重新打包后的资源；遇到不匹配时停止。

如果安装在其他位置，可先设置环境变量。例如在当前目录下的 `Antigravity` 文件夹中安装了客户端：

```powershell
$env:ANTIGRAVITY_INSTALL_DIR = (Resolve-Path .\Antigravity).Path
node .\patch.js
```

如果希望自行控制退出和重启，可在完全退出客户端后运行：

```powershell
node .\patch.js --no-kill
```

`--no-kill` 只跳过脚本中的关闭、启动步骤；它不会让运行中的界面立即更新。完成后需自行重新启动 Antigravity。

## 自动中文会话标题（可选）

此功能默认关闭。它通过当前 Antigravity 账号的模型服务翻译新会话自动生成的短标题，会额外使用模型请求或额度；每个待处理新标题最多请求两次。只发送标题文本，不发送聊天正文，不需要额外插件、独立后台进程或另外配置 API 密钥。

首次启用时已存在的会话会加入保留名单，不会回溯重命名。之后的新主会话在自动标题稳定后处理，通常需要十几秒至数十秒。完成自动处理后不再反复改写同一会话名称。子会话、已有中文标题及部分特殊会话会跳过。服务失败时可能保留英文；本功能不是对后台原生命名器的语言保证。

启用：保存工作并退出 Antigravity，在补丁目录双击 `enable-chinese-titles.cmd`，再运行 `install.cmd`（已经安装本版的用户重新启动 Antigravity 即可）。也可以使用：

```powershell
node .\configure-chinese-titles.cjs --enable
```

关闭：保存工作并退出 Antigravity，双击 `disable-chinese-titles.cmd`，或运行以下命令后重新启动。关闭后已生成的中文标题仍然保留。

```powershell
node .\configure-chinese-titles.cjs --disable
```

上述设置仅在下次启动时读取，不会中断正在执行的任务。脚本只更改 `%APPDATA%\Antigravity\chinese-title-settings.json` 中的启用选项，不清空历史处理名单。处理状态和诊断分别保存在同目录的 `chinese-title-state.json`、`chinese-title-status.json`，不保存标题正文或认证值。模型服务及内部接口只在本地 `127.0.0.1` 连接，已验证客户端 2.32.1 和 2.32.2；未来版本需重新核对接口。

## 新项目和新规则的中文偏好

自动中文标题功能不自动修改你的全局智能体规则。如果希望智能体生成的新项目显示名、规则标题和自然语言正文默认中文，可将 [中文偏好示例](examples/chinese-default-rules.md) 追加到 `%USERPROFILE%\.gemini\GEMINI.md`，保留原有内容；无需每个项目重复添加。项目专属要求和用户当次指定的语言仍应遵循。软件随机生成的临时项目名称未修改，规则文件名、代码、路径和技术名称仍保留原文。

## 还原英文界面

保存工作、退出 Antigravity，并在本仓库目录中执行：

```powershell
node .\patch.js --revert
```

还原依赖安装目录中由脚本创建的 `resources/app.asar.bak` 及 `resources/app.asar.bak.json` 校验记录。请同时保留，不要把旧客户端版本的备份用于新版本。对于上游旧版未带校验记录的备份，脚本会先核对版本、文件结构和补丁标记，再补建记录；已汉化却没有原版备份时会停止。
